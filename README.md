# 📊 HDFC-Bank-Stock-Market-Analysis-Dashboard
An interactive Power BI dashboard that provides deep insights into stock performance of HDFC Bank using historical market data.

📌 Project Overview
This project analyzes stock trends using key financial indicators such as 52-week high/low, trading volume, opening & closing prices, and time-based filters.
The dashboard helps in understanding:
- Market trends 📈
- Price fluctuations 📉
- Trading behavior over time ⏳

📅 Dataset Information
- <b>Dataset Name:<b> HDFC Bank Equity Stock Data
- <b>Time Period:<b> 30 March 2025 – 30 March 2026
- <b>Data Type:<b> Daily stock market data
- <b>Attributes Included:<b>
     - Open Price
     - Close Price
     - High & Low
     - Volume
     - Date (Day, Month, Quarter, Year)
       
📊 Key Features
- 📈 52-Week Analysis
     - Avg High: 2.02K
     - Avg Low: 1.16K 
- 📊 Trading Insights
     - Total Volume: 5 Billion
     - Open vs Close comparison
- 📅 Time-Based Filters
     - Quarter-wise (Q1–Q4)
     - Month & Day filters
     - Year selection
  
🔍 Insights Generated
- 📌 Highest trading volume observed in March
- 📌 Consistent stock performance across quarters
- 📌 Daily fluctuations between 8.5K – 13.4K
- 📌 Sudden drop at month-end indicates possible market correction
- 📌 Peak activity observed mid-week (Tuesday)

🛠️ Tools & Technologies Used
- Power BI
- Data Cleaning & Transformation
-  DAX (Data Analysis Expressions)
-  Data Visualization Techniques
